# NeoCalc Pro

Aplicativo de apoio clínico em Pediatria e Neonatologia.

## Funcionalidades
- Calculadoras neonatais
- Gasometrias seriadas
- Ventilação mecânica neonatal
- Hidratação e eletrólitos
- Medicações neonatais
- NeoMonitor: acompanhamento clínico neonatal

## Plataforma
Aplicativo PWA para Android, iPhone e computador.

## Segurança
Os dados clínicos deverão ser protegidos. O aplicativo será desenvolvido inicialmente com dados fictícios.
